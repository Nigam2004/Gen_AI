## Install uv Enviroment

Download and install **uv** in your project file terminal(powershell):

```bash
irm https://astral.sh/uv/install.ps1 | iex
```


## check the version of uv

After installing Miniconda, open **Git Bash** and run:

```bash
uv --version
```
You should see something similar to:

```text
uv 0.12.23 (46b84fd0b 2026-10-03 x86_64-pc-windows-msvc)
```

### install venv
```bash
uv venv
```
### Activate the  Environment

If your environment is named `.venv`, activate it using:

```bash
.venv\Scripts\activate
```
